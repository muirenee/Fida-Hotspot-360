# v0.2.0 security-first implementation

## Current implementation
- Types and deny-by-default tenant/property authorization contract.
- Validated OIDC-claims mapper, explicitly not a JWT verifier.
- Unit tests for cross-tenant, cross-property, anonymous access and roles.
- Tenant-management API endpoints are not enabled until JWT validation and DB membership lookup exist.

## Next acceptance gates
1. Configure a supported OIDC IdP with issuer, audience, JWKS rotation and expiry tests.
2. Add membership tables and PostgreSQL tenant-scoped security policies.
3. Add authenticated hotel/property CRUD with authorization tests.
4. Add local edge enrollment with expiring one-use tokens and mutual TLS.
5. Configure FreeRADIUS SQL locally and test authentication and accounting.
6. Validate actual OPNsense integration before claiming guest Wi-Fi connectivity.

Security note: no production credentials, JWT bypasses, or hardcoded secrets.
